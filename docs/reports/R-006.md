# R-006 localStorage → 文件持久化(桌面端)

## 议题
- Python `ask.html` 错题本用浏览器 `localStorage` 存(键 `exam.wrong_book`)。
- Dioxus 0.7.9 desktop 是 WebView 进程,理论上可用 localStorage,但:
  1. WebView 容器不保证持久化(sandbox 可能清理)
  2. 多 WebView 实例隔离,跨 session 不可见
  3. 与 system-level 配置(主题 / 数据源)语义不同,合在一处易混

## 决策
**桌面端错题本 + 设置都走 JSON 文件,目录 = `dirs::config_dir()` 的 `exam-lookup-rs/` 子目录。**

具体:
- `crates/exam-app/src/state.rs::default_settings_path()` → `~/Library/Application Support/exam-lookup-rs/settings.json`(macOS)
  - Linux: `~/.config/exam-lookup-rs/settings.json`
  - Windows: `%APPDATA%\exam-lookup-rs\settings.json`
- `crates/exam-app/src/wrongbook.rs::WrongBookStore::load_or_default()` → 同目录下 `wrong.json`。
- 用 `dirs = "5"` crate 跨平台拿到 config 目录(不依赖 `$HOME` 直读)。

## 为什么不用 localStorage
- WebView 持久化弱,卸载应用可能清。
- 跨平台导出(用户想把错题本拷到另一台机器)走文件比走 devtools 友好。
- 测试更直接:文件系统读写可用 tempfile,不需要起 WebView。

## 验证
- 5 个 wrongbook 单元测试(roundtrip / dedupe / remove / export_json / clear)。
- 1 个 settings 主题枚举 roundtrip 测试。
