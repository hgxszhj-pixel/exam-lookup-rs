# R-003 Dioxus desktop 首次 build 耗时

## 议题
- Dioxus 0.7.9 引入大量宏(`#[component]` / `#[derive(Routable)]`)和生成代码。
- 首次 `cargo build` 拉满所有 transitive deps(dioxus-core / dioxus-signals / dioxus-router / dioxus-desktop 自身 + wry + tao)。
- 实测 macOS Apple Silicon 首次冷构建约 4-6 分钟,Intel Mac 约 6-9 分钟。

## 决策
**接受现状,本地 / CI 各取所需。**

### 本地
- 用 `cargo nextest` 跑测试(增量 build 缓存友好,跑 78 个测试 ~5s 增量)。
- 用 `cargo build --release` 出 `.app` 时允许一次性等待(本地手动触发)。

### CI(若后续接入)
- 加 `RUSTFLAGS="-C debuginfo=0"` + `sccache` 复用 object 缓存。
- 用 `mold` / `lld` link 加速。

## 验证
- 实测:`cargo build --release` 首次 5m20s,二次 14s(纯 link)。
- 实测:`cargo test --workspace` 增量 5s。

## 风险
- 首次 build 久会降低开发体验;但**仅首次**。
- 二进制体积:`exam-app` release 产物 ~28MB(无 upx 压缩),可接受(桌面端非寸土寸金)。

## 状态
- 落地:Phase E `crates/exam-app/Cargo.toml` 用 `dioxus = { version = "0.7.9", features = ["desktop"] }`。
- 不做 sccache(本机单人开发,缓存收益边际)。
