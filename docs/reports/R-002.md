# R-002 PDF / 文档解析依赖

## 议题
- 计划中提到 `crates/exam-engine/src/source/doc_index.rs` 负责 `docs/*.pdf` / `docs/*.html` 索引。
- PDF 解析在 Rust 生态有 3 个常见选择:
  1. 系统命令 `pdftotext`(poppler-utils)
  2. `pdf-extract` crate(pure Rust,依赖 `lopdf`)
  3. `lopdf` 自解析(更底层)

## 若后续开启
- 选 `pdf-extract`(zero-config、无系统依赖);若二进制体积敏感,改 `lopdf` 直接拉文本流。
- HTML 解析选 `scraper`(CSS selector,与 Python BeautifulSoup 语义对齐)。
- Markdown 解析选 `pulldown-cmark`(若要索引 `*法条对照.md`)。
- 都需新建 `source::doc_index`,在 `source/mod.rs` 加 `pub mod doc_index;` + `inventory::submit!`。
