# R-005 inventory 在 wasm 端的支持

## 议题
- `inventory` crate 用 `link_section` ELF/Mach-O 自定义段实现跨 crate 全局注册表。
- WebAssembly 链接模型与传统可执行文件不同:`link_section` 不被 wasm-ld 原生支持。
- 计划 `source/*.rs` 同时供 desktop GUI 与潜在 future web 端共享。

## 决策
**当前 Phase F 仅 desktop 端启用 inventory,wasm 端不在范围内。**

具体:
- `crates/exam-engine/src/source/mod.rs` 用 `inventory::collect!(SourceEntry)` —— 仅编译进 `lib` 的 native target。
- 不引入 wasm build target(无 Dioxus SSR / WASM 配置)。
- 若未来需要 wasm:换 `linkme` crate(`inventory` 作者的 wasm-safe 替代品,API 几乎一致)。

## 验证
- `cargo build --target x86_64-apple-darwin`:OK(Phase E 验证)。
- `cargo build --target wasm32-unknown-unknown`:不尝试(无 wasm frontend)。

## 风险
- 单一 desktop target,迁移到 web 时需替换 inventory → linkme。代码改动仅 `source/mod.rs` 的 `inventory::collect!` / `submit!` → `linkme::distributed_slice!` / `linkme::distributed_slice!(…)`。

## 状态
- 计划 out-of-scope 条目保留:不做 wasm / 移动端(plan §9)。
