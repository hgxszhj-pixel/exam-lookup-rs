# R-012 — Phase I+: SettingsPage 主题实时预览

> 写入者: Claude Code(2026-10-04)
> 范围: `exam-app::SettingsPage` 主题切换 UX

---

## 目标

1. 主题 `<select>` 选中即应用到 `html[data-theme]`,无需先点「保存」。
2. 提供 `↻` 循环按钮: System → Light → Dark → System,作为键盘可达的快速切换。
3. 「保存」按钮职责收敛为「落盘到 settings.json」,不再触发主题应用。

---

## 改动

| 文件 | 变更 |
|---|---|
| `crates/exam-app/src/ui/settings.rs` | `select.onchange` 调 `apply_theme_to_root(next)`;新增 `↻` 按钮做 Theme 循环 |

---

## 设计权衡

- **不循环预览**: 即时 preview 而非 dark-mode-style 切换 — 用户视觉连续,不需要「撤销」。
- **状态分离**: `theme` signal 仅是 UI 状态,真正落盘靠「保存」按钮 — 避免每个 onchange 都写盘(写盘可能 IO 失败 + 噪音)。
- **按钮文案**: 单字符 `↻`(U+21BB)足够表意,不需要 `切换主题` 长文案;`title` 属性补全可达性提示。
- **不引入 watcher**: 主题循环/预览是单用户本地操作,`notify` 文件监听对场景无收益 — 留作未来多选;当前无需扩展抽象。
