# R-004 Dioxus 0.7.9 版本锁定

> ⚠ **2026-11-04 复核:本决策**从未落地**。** 详见下方 [§ 实际状态](#实际状态2026-11-04)。

## 议题
- Dioxus 0.7.x 在 0.7.0 → 0.7.9 之间有多次破坏性 patch(尤其 `Router` API)。
- 计划版本从调研时点(2026 上半年)的最新 0.7.x 锁定为 0.7.9。
- 0.7.10+ 可能引入新一轮 API 调整(如 `Outlet` 用法变化、`#[layout]` 属性语义)。

## 决策
**`Cargo.toml` 锁版本号 `0.7.9`,禁止 `^0.7` 自动 bump。**

具体:
- `crates/exam-app/Cargo.toml`: `dioxus = { version = "=0.7.9", ... }` / `dioxus-router = "=0.7.9"`。
- workspace 根 Cargo.toml `rust-version = "1.76"`:Dioxus 0.7.9 的 `#[component]` 宏要求 MSRV ≥ 1.76(原 1.75 报 `incompatible_msrv` clippy 错误,已修)。

## 不引入未来 0.7.10+ 的功能
- ❌ 0.7.10 实验性 hot reload(可能引入 API 调整)
- ❌ 0.8.x(`use_signal` / `use_context_provider` 重命名概率高)

## 升级路径(若必须)
1. 阅读 dioxus CHANGELOG.md
2. 单独 commit:`chore: bump dioxus 0.7.9 → 0.7.N`
3. 跑全量测试(当前 153)+ clippy
4. GUI smoke test(Phase E 的 4 tab 全点一遍)

```toml
# crates/exam-app/Cargo.toml
dioxus = { version = "0.7.9", features = ["desktop"] }   # caret,不是 "=0.7.9"
```
