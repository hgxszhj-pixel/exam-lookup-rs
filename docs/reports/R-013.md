# R-013 — Phase I++: SettingsPage 主题色板预览条

> 写入者: Claude Code(2026-10-04)
> 范围: `exam-app::SettingsPage` 主题可视化

---

## 目标

1. 在主题设置下方放 5 个色块: `--bg / --card / --accent / --success / --danger`,作为主题色板 live preview。
2. 零事件: 不挂任何 `onclick`,色块直接读 CSS 自定义属性;根 `[data-theme]` 切换时浏览器自动重渲。
3. 右侧附主题文字说明,主题切换时同步刷新。

---

## 改动

| 文件 | 变更 |
|---|---|
| `crates/exam-app/src/ui/settings.rs` | 在主题 select+cycle 之后插入 5 个 swatch div + 一段 match(theme()) 文字 |

---

## 设计权衡

- **零事件预览**: 利用 CSS 自定义属性继承语义 — 色块 `background:var(--accent)` 自动跟随根 `data-theme` 变化。比写 JS 重渲简单 100 倍,bug 概率接近 0。
- **选 5 色而非 7**: `--fg / --muted / --accent-fg` 在浅色背景上与 `--bg / --card` 对比度低,作为色板意义不大;保留 5 个高对比色。
- **文字说明用 `match`**: 在 89/89 tests 已绿的 Rust 信号体系里,`match theme() { ... }` 编译期保证三个分支全覆盖,比字符串拼接安全。
