### 3. 主题同步 (`state.rs` + `app.rs` + `settings.rs`)

```rust
impl Theme {
    pub fn data_attr(self) -> Option<&'static str> {
        match self {
            Self::Light => Some("light"),
            Self::Dark => Some("dark"),
            Self::System => None,
        }
    }
}

pub fn apply_theme_to_root(theme: Theme) {
    let script = match theme.data_attr() {
        Some(v) => format!("document.documentElement.setAttribute('data-theme','{v}');"),
        None => "document.documentElement.removeAttribute('data-theme');".to_string(),
    };
    let _ = dioxus::document::eval(&script);
}
```

启动时 `App` 调一次,Settings 保存后再调一次。`System` 不写 attr,由 CSS `@media (prefers-color-scheme: dark)` 兜底。

## 踩坑

1. **`document::KeyListener` 不存在** — Dioxus 0.7 没有这个 component。改成顶层 div
   `tabindex=0` + `onkeydown`(dioxus desktop 默认焦点在根)。
2. **`Key::as_str()` 不存在** — `dioxus::prelude::Key` 是 enum,没有 `as_str`。
   改用 `Key::Character("?".into())` 直接匹配。
3. **web_sys 不可用** — `web_sys` crate 没列在 exam-app deps,desktop 端没必要引。
   改用 `dioxus::document::eval()` 跑 JS。
4. **DbStatusBanner 跨文件复用** — `ask.rs` 定义,CardsPage 用 — 必须 `pub` 暴露,
   否则 `mod ui; pub use ask::AskPage;` 之外不可见。

## 已知 caveat / 后续 watch

- `/` 全局聚焦:目前不分页面 — Practice / WrongBook 上按 `/` 也会试图聚焦,
  但目标元素不存在,JS `if (el)` 静默跳过,体验无副作用,语义略糙,后续可加路由守卫。
- DB 路径修改后仍要重启 — Settings 改 `data_root` / `db_path` 时仅写盘,不重新 bootstrap。
  真要"实时生效"需要在 Settings 加"重新加载 DB"按钮,Phase K 文档化。
- 主题 `System` 不写 `data-theme` attr — 依赖 CSS media query。如果用户的 CSS
  把 `[data-theme="light"]` 当作强制浅色,System 切换时不会立刻跟,需要 reload。
  已在 CSS 注释中说明。
